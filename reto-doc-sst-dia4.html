📊 Dashboard SST Automatizado con IA

Objetivo del día: Crear un dashboard de indicadores SST usando IA + Excel/Google Sheets que se actualice con mínima intervención manual, permitiendo tomar decisiones rápidas y basadas en datos.

📊 KPIs esenciales del Dashboard SST

Indicadores reactivos (lo que ya pasó):
  • Número de accidentes (con y sin tiempo perdido)
  • Tasa de accidentabilidad (TA)
  • Tasa de frecuencia (TF) y tasa de gravedad (TG)
  • Días perdidos por accidente
Indicadores proactivos (lo que puedes controlar):
  • Inspecciones realizadas vs. programadas
  • Observaciones de seguridad cerradas
  • Capacitaciones completadas
  • Equipos de protección personal (EPP) entregados
  • Investigaciones de incidentes cerradas

🛠️ Pasos para construir el Dashboard con IA

Paso 1: Define los KPIs que necesitas medir en tu empresa/rubro.
Paso 2: Usa IA para generar la estructura de la hoja de cálculo con fórmulas automáticas.
Paso 3: Solicita a la IA que cree gráficos de semáforo (rojo/amarillo/verde) por indicador.
Paso 4: Automatiza el cálculo de tasas con fórmulas: TA = (N° accidentes / N° trabajadores) x 100.
Paso 5: Agrega una pestaña de resumen ejecutivo que se actualice sola.
Paso 6: Pide a la IA que genere un prompt para el análisis mensual automático.
Paso 7: Exporta como PDF para reportes a gerencia.

🤖 Superprompt para crear el Dashboard SST con IA

Actúa como un experto en SST y análisis de datos. Necesito crear un Dashboard SST para una empresa de [rubro] con [N°] trabajadores. Crea una estructura completa en Google Sheets / Excel que incluya: 1. Hoja de DATOS BASE: donde ingreso mensualmente accidentes, inspecciones, capacitaciones. 2. Hoja de KPIs: con fórmulas automáticas para calcular: - Tasa de accidentabilidad = (accidentes / trabajadores) x 100 - Tasa de frecuencia = (accidentes / horas trabajadas) x 1.000.000 - % cumplimiento de inspecciones - % capacitaciones completadas 3. Hoja DASHBOARD visual con: - Semáforos (rojo/amarillo/verde) por KPI - Gráfico de tendencia mensual - Resumen ejecutivo de 5 líneas para gerencia 4. Fórmulas listas para copiar. Formato: dame primero la estructura de columnas, luego las fórmulas y finalmente el resumen ejecutivo del mes.

✅ Checklist final del Día 4

  • El dashboard incluye indicadores reactivos Y proactivos.
  • Las fórmulas se calculan automáticamente al ingresar datos.
  • Existe un semáforo visual por cada KPI clave.
  • El resumen ejecutivo se puede generar con IA en 2 minutos.
  • El archivo está listo para compartir con gerencia.
